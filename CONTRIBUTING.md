# Contributing to NearDesk

Thanks for helping. Keep the process light.

## Before you start

1. Search existing issues and PRs.
2. For anything larger than a typo or tiny fix, open an issue first so we can align on scope.
3. One PR ≈ one concern.

## Development

- Target: macOS client for Mac ↔ Mac LAN screen sharing.
- Prefer small, reviewable diffs and clear commit messages.
- Do not copy UI or marketing wording from Apple’s system “Screen Sharing” / 「屏幕共享」 product; use NearDesk’s own labels.

## Pull requests

- Describe **what** changed and **why**.
- Link related issues.
- Note how you tested (or why testing wasn’t possible yet).
- Keep LICENSE / NOTICE headers intact on new source files when you add them.

## Conduct

Be respectful. Assume good intent. Maintainers may close off-topic or hostile threads.
